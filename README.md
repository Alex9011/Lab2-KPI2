# Лабораторна робота №2 — UC та вимоги (бібліотека)

Основа: [ЛР1 з бібліотеки](https://github.com/Alex9011/Lab1_KPI2) — `Book`, `Author`, `Copy`, `Member`, `Loan`.

## Файли

- [`spec.md`](spec.md) — актори та UC, сценарії Gherkin, EARS, NFR, поза обсягом, матриця трасування, аудит.
- [`diagram.puml`](diagram.puml) — вихідний код UC-діаграми в PlantUML.
- [`diagram.svg`](diagram.svg) — схема прецедентів для перегляду.
- [`DEFENSE.md`](DEFENSE.md) — аргументи для захисту.
- [`ai/`](ai/) — мета роботи з AI, історія промтів, аудит, приклади версій і допоміжний скрипт рендеру.

**Основний UC:** UC-05 «Оформити видачу примірника». Обсяг: 8 сценаріїв, 16 EARS-вимог, 8 вимірюваних NFR.

**Увага:** NFR і частина поведінкових деталей є припущеннями для погодження. Викладач вимагає власноруч сформульованих і перевірених `spec.md` та `DEFENSE.md`; цей комплект слід використати як підготовлений проєкт для власного рев'ю. Текст `ai/prompt.md`.

## Перевірка

```bash
python ai/check.py
python ai/render.py
```

Для перегенерації оригінальної UML-діаграми бажано мати `plantuml`; `ai/render.py` формує еквівалентний оглядовий SVG через Graphviz `dot`.
